# Frozen release outputs

This directory contains the immutable paper-facing outputs for repository release **v1.0.0**.

- `supplementary_tables/`: complete Supplementary Tables S1-S21 and inventory.
- `main_figures/`: final main figures, including the integrated specificity/subtype/reference-validation figure.
- `supplementary_figures/`: final supplementary figures.
- `final_validation/`: concise pan-cancer, PurIST and CIBERSORTx validation tables plus compressed sample-level audit tables.

These files are included for auditability. Regenerated outputs may differ slightly if upstream public resources or online annotation services change.
