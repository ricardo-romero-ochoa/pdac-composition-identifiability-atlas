# Release v1.0.0

Initial public archival release of the PDAC composition-identifiability atlas.

This release freezes:

- six-cohort GEO discovery/meta-analysis;
- v3.14 composition-identifiability audit;
- TCGA/GTEx validation and survival analysis;
- single-cell localization;
- pan-cancer specificity analysis;
- PurIST sample-level subtype validation;
- final CIBERSORTx reference-based composition validation;
- prior-art and subtype-signature overlap;
- DepMap/Open Targets annotation;
- all paper-facing supplementary tables and figures.

The archive contains only public analysis code, reproducibility documentation, curated resources, and frozen release outputs.
